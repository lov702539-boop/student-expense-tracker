# Student Expense Tracker

A beginner-friendly command-line Python project for recording and reviewing daily student expenses.

## Features
- Add expenses with a category, description, and amount
- Save records locally in a CSV file
- View expense history
- See total and category-wise spending summaries
- Validate amounts and handle invalid input

## Technology
- Python 3
- CSV module
- File handling
- Functions and exception handling

## Run the project
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python main.py
```

The program creates `expenses.csv` automatically when the first expense is added.

## Learning note
This is an educational portfolio project. Try adding features such as monthly reports, editing/deleting expenses, or a graphical interface.
